# IT Club Website

A CMS-based website for the IT Club, designed to be flexible and reusable for other clubs in the future.  
The system allows dynamic control over homepage sections, themes, and content visibility.

This project is developed as a college club initiative.

---

## 🚀 Features (Current & Planned)
- CMS-style homepage management
- Enable/disable sections dynamically
- Theme customization per section
- Admin-managed content
- Dockerized development environment

---

## 🛠 Tech Stack
- Python 3.14
- Django 5.2.9
- SQLite (default)
- MySQL 8 (Docker)
- Docker & Docker Compose
- Whitenoise (static serving)
- Gunicorn (production WSGI)
